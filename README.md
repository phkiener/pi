# pi in a pod

```sh
./run-pi.sh # run a preconfigured pi-session in the current working directory
```

It's very opinionated, tailored to my taste. I'll see if I keep using it.

## Installation

Clone the repo and you're ready to go. You'll probably want to add a symlink:

```sh
ln -s /path/to/repo/run-pi.sh ~/.local/bin/run-pi.sh
```
